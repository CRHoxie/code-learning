> `<ctype.h>` 提供字符分类判断和大小写转换函数。  
> 所有分类函数的参数类型都是 `int`，返回值也是 `int`：满足条件返回非零值，不满足返回 `0`。

---

## 1. 使用要点

```c
#include <ctype.h>
```

### 参数传递规则

`<ctype.h>` 中函数的参数 `c` 必须满足以下之一：

1. 可表示为 `unsigned char` 的字符值；
2. 等于 `EOF`。

错误示例：

```c
char c = -1;          /* 若 char 有符号，可能是负值 */
isalpha(c);           /* 错误：可能传入负值，行为未定义 */
```

正确写法：

```c
isalpha((unsigned char)c);
```

读取字符时推荐：

```c
int ch;
while ((ch = getchar()) != EOF) {
    if (isalpha(ch)) {
        /* ... */
    }
}
```

因为 `getchar()` 返回 `int`，可以安全表示 `EOF` 或 `unsigned char` 值。

## 2. 标准函数总览

### 2.1 字符分类函数

| 函数 | 原型 | 判断内容 | 返回真示例 | 说明 |
|---|---|---|---|---|
| `isalnum` | `int isalnum(int c);` | 字母或数字 | `'A'`, `'7'` | `isalpha(c) || isdigit(c)` |
| `isalpha` | `int isalpha(int c);` | 字母 | `'A'`, `'z'` | 是否字母受 locale 影响 |
| `isblank` | `int isblank(int c);` | 空白字符 | `' '`, `'\t'` | C99 起支持；空格或水平制表符 |
| `iscntrl` | `int iscntrl(int c);` | 控制字符 | `'\n'`, `'\0'` | 如换行、回车、退格等 |
| `isdigit` | `int isdigit(int c);` | 十进制数字 | `'0'` 到 `'9'` | 仅十进制数字 |
| `isgraph` | `int isgraph(int c);` | 可显示且非空格字符 | `'!'`, `'A'` | 可打印字符中排除空格 |
| `islower` | `int islower(int c);` | 小写字母 | `'a'`, `'z'` | 受 locale 影响 |
| `isprint` | `int isprint(int c);` | 可打印字符 | `' '`, `'A'` | 包含空格 |
| `ispunct` | `int ispunct(int c);` | 标点符号 | `','`, `'!'` | 可打印、非字母数字、非空格 |
| `isspace` | `int isspace(int c);` | 空白字符 | `' '`, `'\n'`, `'\t'` | 空格、换页、换行、回车、制表、垂直制表 |
| `isupper` | `int isupper(int c);` | 大写字母 | `'A'`, `'Z'` | 受 locale 影响 |
| `isxdigit` | `int isxdigit(int c);` | 十六进制数字 | `'0'`, `'9'`, `'A'`, `'f'` | `0-9`、`a-f`、`A-F` |

### 2.2 大小写转换函数

| 函数 | 原型 | 作用 | 示例 |
|---|---|---|---|
| `tolower` | `int tolower(int c);` | 若 `c` 是大写字母，返回对应小写；否则返回 `c` | `tolower('A')` 返回 `'a'` |
| `toupper` | `int toupper(int c);` | 若 `c` 是小写字母，返回对应大写；否则返回 `c` | `toupper('z')` 返回 `'Z'` |

注意：

```c
char ch = (char)toupper((unsigned char)c);
```

`tolower` 和 `toupper` 返回 `int`，通常需要转换为 `char` 后保存。

## 3. 常用函数详解

### 3.1 `isalpha`

```c
int isalpha(int c);
```

判断字符是否为字母。

```c
if (isalpha('A')) {
    puts("是字母");
}
```

---

### 3.2 `isdigit`

```c
int isdigit(int c);
```

判断字符是否为十进制数字 `0` 到 `9`。

```c
if (isdigit('7')) {
    puts("是数字");
}
```

注意：`isdigit('A')` 为假，`isxdigit('A')` 为真。

---

### 3.3 `isalnum`

```c
int isalnum(int c);
```

判断字符是否为字母或数字。

```c
if (isalnum('X') || isalnum('8')) {
    puts("是字母或数字");
}
```

---

### 3.4 `isspace`

```c
int isspace(int c);
```

判断是否为空白字符，通常包括：

- 空格 `' '`
- 换页 `'\f'`
- 换行 `'\n'`
- 回车 `'\r'`
- 水平制表 `'\t'`
- 垂直制表 `'\v'`

```c
if (isspace('\n')) {
    puts("是空白字符");
}
```

---

### 3.5 `isblank`

```c
int isblank(int c);
```

C99 引入，判断是否为空格或水平制表符：

```c
if (isblank(' ') || isblank('\t')) {
    puts("是水平空白字符");
}
```

与 `isspace` 相比，`isblank` 不包含换行、回车等。

---

### 3.6 `isprint` 与 `isgraph`

```c
int isprint(int c);
int isgraph(int c);
```

- `isprint(c)`：判断是否为可打印字符，包含空格。
- `isgraph(c)`：判断是否为可显示字符，排除空格。

```c
isprint(' ');   /* 真 */
isgraph(' ');   /* 假 */
isgraph('A');   /* 真 */
```

---

### 3.7 `ispunct`

```c
int ispunct(int c);
```

判断是否为标点符号，即：可打印、不是字母数字、也不是空格。

```c
if (ispunct(',')) {
    puts("是标点符号");
}
```

---

### 3.8 `iscntrl`

```c
int iscntrl(int c);
```

判断是否为控制字符，例如换行、回车、退格等。

```c
if (iscntrl('\n')) {
    puts("是控制字符");
}
```

---

### 3.9 `isxdigit`

```c
int isxdigit(int c);
```

判断是否为十六进制数字：

- `0` 到 `9`
- `a` 到 `f`
- `A` 到 `F`

```c
if (isxdigit('F')) {
    puts("是十六进制数字字符");
}
```

---

### 3.10 `tolower` 与 `toupper`

```c
int tolower(int c);
int toupper(int c);
```

示例：

```c
int a = tolower('A');   /* a == 'a' */
int b = toupper('z');   /* b == 'Z' */

char c = (char)tolower((unsigned char)'Q');
```

注意：

- 如果参数不是对应大小写字母，函数通常返回原值。
- 结果受当前 locale 影响。
- 返回值类型为 `int`。

## 4. 综合示例

```c
#include <stdio.h>
#include <ctype.h>

int main(void)
{
    const char *text = "C99: Hello, World!\n";
    const unsigned char *p;

    for (p = (const unsigned char *)text; *p != '\0'; ++p) {
        unsigned char c = *p;

        if (isalpha(c)) {
            printf("字母: %c\n", c);
        } else if (isdigit(c)) {
            printf("数字: %c\n", c);
        } else if (isspace(c)) {
            printf("空白: 0x%02X\n", (unsigned int)c);
        } else if (ispunct(c)) {
            printf("标点: %c\n", c);
        }
    }

    printf("tolower('A') = %c\n", tolower((unsigned char)'A'));
    printf("toupper('z') = %c\n", toupper((unsigned char)'z'));

    return 0;
}
```

## 5. 安全封装示例

```c
#include <ctype.h>

int is_alpha_safe(char ch)
{
    return isalpha((unsigned char)ch);
}

char to_lower_safe(char ch)
{
    return (char)tolower((unsigned char)ch);
}

char to_upper_safe(char ch)
{
    return (char)toupper((unsigned char)ch);
}
```

## 6. 常见陷阱

### 陷阱 1：直接把可能为负值的 `char` 传入函数

```c
char c = '\xFF';
isalpha(c);              /* 可能错误 */
isalpha((unsigned char)c); /* 正确 */
```

### 陷阱 2：把返回值当作一定为 `1`

这些函数只保证：

- 不满足条件返回 `0`；
- 满足条件返回非零值。

不要写：

```c
if (isalpha(c) == 1) { /* 不推荐 */ }
```

推荐：

```c
if (isalpha(c)) { /* 正确 */ }
```

### 陷阱 3：忽略 locale

`isalpha`、`islower`、`isupper`、`tolower`、`toupper` 等行为可能受当前 locale 影响。默认 C locale 下通常表现为常见 ASCII 字符分类，但不要假设所有环境完全一样。

### 陷阱 4：混淆 `isdigit` 与 `isxdigit`

```c
isdigit('A');   /* 假 */
isxdigit('A');  /* 真 */
```

## 8. 总结

- `<ctype.h>` 主要用于字符分类和大小写转换。
- 参数应传入 `unsigned char` 值或 `EOF`。
- 分类函数返回“非零 / 零”，不要假定非零一定等于 `1`。
- `tolower` / `toupper` 不修改原变量，而是返回转换后的值。
- 字符分类和转换行为可能受 locale 影响。
- 处理字符串中的 `char` 时，推荐写成：

```c
isalpha((unsigned char)ch)
toupper((unsigned char)ch)
```
